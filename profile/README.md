# ICP · Insurance MCP

금융회사 내부 AI 에이전트가 어떤 모델을 쓰든, 보험 데이터에서 필요한 사실을
정확하게 꺼내 근거와 함께 설명할 수 있게 하는 MCP 도구를 만듭니다.

가천대학교 AI P-실무프로젝트 SW 2분반 5조 · 한국신용정보원 기업과제

## 주요 기능

- 보험 청구 이력 조회
- 사고 관계 탐색
- 청구 패턴 분석
- 규칙 기반 위험 판정 (근거·기준일 함께 반환)

## 기술 스택

Python · MCP SDK · FastAPI · Docker · OAuth 2.1 · DeepEval · Langfuse
